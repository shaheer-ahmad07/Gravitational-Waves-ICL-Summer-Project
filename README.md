# Gravitational-Waves-ICL-Summer-Project

Signal Processing Pipeline 
Designed and implemented a full data processing pipeline to extract gravitational wave signals from noisy LIGO observational data. Implemented Butterworth bandpass filtering and cross-correlation matched filtering techniques to isolate the GW150914 signal from background noise.

Model Validation 
Generated synthetic gravitational waves using Newtonian physics models and validated their accuracy against real-world LIGO data. Achieved Signal-to-Noise Ratio (SNR) of 8.0 (detection threshold) and parameter fitting estimates within 3 standard deviations of published values.

Data Visualisation 
Created comprehensive visualizations using Python libraries to: Generate 2D and 3D model simulations of binary black hole mergers Highlight signal characteristics across different noise conditions Compare model predictions across varying sampling rates
